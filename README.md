# 🎈 FunnyKids – Kids Learning Website

FunnyKids is an educational website designed to make learning fun and interactive for children. It provides simple learning activities, quizzes, poems, and language lessons in a child-friendly environment.

## 🌟 Features

- **Lessons:** Interactive lessons for children.
- **Quizzes:** Fun quizzes to support learning.
- **Poems:** A collection of enjoyable poems.
- **Telugu Learning:** Learn Telugu letters and pronunciation.
- **Hindi Learning:** Explore Hindi letters and pronunciation.
- **English Lessons:** Read lessons with text-to-speech support.
- **Voice Support:** Listen to English and Hindi lesson content using available browser voices.
- **Child-Friendly Design:** Simple and engaging interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Speech API
- Git and GitHub
