# 🎨 FunnyKids — Kids Learning Website

An interactive kids' learning website built using HTML5, CSS3, and JavaScript. FunnyKids helps children learn through fun lessons, quizzes, poems, and language-learning activities.

## 🚀 Features

- 🏠 Home page with a colorful, child-friendly design
- 📚 Interactive lessons for children
- 🧠 Fun quizzes and learning activities
- 🎵 Kids' poems and background music
- 🌈 Telugu language learning
- 📖 Hindi language learning
- ⭐ Rewards section
- 🖼️ Colorful images and visual elements
- 🔊 Audio and music controls
- 📱 Browser-based learning experience

## 🛠️ Technologies Used

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript
- 🎵 HTML Audio
- 🖼️ Images and multimedia assets

## 📂 Project Pages

- 🏠 `index.html` — Home page
- 📚 `Lessons.html` — Learning activities
- 🧠 `Quizzes.html` — Quizzes
- 🎼 `Poems.html` — Kids' poems
- 🌈 `Telugu.html` — Telugu learning
- 📖 `Hindi.html` — Hindi learning

## 💻 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Explore the lessons, quizzes, poems, and language-learning pages.
